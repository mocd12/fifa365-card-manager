# FIFA 365 Card Manager

Simple bilingual (English / Hebrew) web app to manage your **Panini FIFA 365 Adrenalyn XL** collectible football cards.

## Features

- Add / remove cards with quantity tracking
- Optional photo attachment (camera or photo library)
- Manual entry of: Name, Card ID, Defence, Midfield, Attack, Total, Country
- Search your collection
- Language toggle (English ↔ Hebrew) with RTL support
- Data stored locally in the browser (localStorage) – works offline

## Live demo

Once GitHub Pages is enabled:

**https://mocd12.github.io/fifa365-card-manager/**

## How to use

1. Open the app on your phone or computer.
2. Switch language with the **עב / EN** button if needed.
3. Go to **Add Card**, fill the form (and optionally attach a photo).
4. View your collection, search, and manage duplicates.

## Tech

- Single HTML file (no build step)
- Pure HTML / CSS / JavaScript
- localStorage for persistence

---

Made for collectors who want a quick offline-friendly way to track their cards.
